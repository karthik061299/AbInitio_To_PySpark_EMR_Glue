## Component-by-Component Validation

### 1. INPUT FILE (Raw Transactions from AWS S3)
- **Ab Initio:** Reads pipe-delimited raw transaction data from S3, applies RAW_DATA_DML_FILE schema.
- **PySpark:**
  - `spark.read.option("delimiter", "|").option("header", "false").schema(raw_input_schema).csv(raw_transactions_path)`
  - **✅ Correct** — Schema, delimiter, and file path logic match.

### 2. INPUT FILE (Product Dimension)
- **Ab Initio:** Reads product dimension file, applies PRODUCT_DIM_DML schema.
- **PySpark:**
  - `spark.read.option("delimiter", "|").option("header", "false").schema(product_dimension_schema).csv(product_dim_path)`
  - **✅ Correct** — Schema, delimiter, and file path logic match.

### 3. REFORMAT (Cleanse & Validate)
- **Ab Initio:** Calls cleanse_validate.xfr, outputs enriched DML, splits rejects.
- **PySpark:**
  - `transform_cleanse_transform(raw_transactions_df)` matches XFR logic (casting, calculation, enrichment).
  - Reject logic: `isnull`, `length(trim())`, `total_amount <= 0` — matches Ab Initio reject conditions.
  - **✅ Correct** — XFR function placement and reject logic.

### 4. DEDUP SORT (Remove Duplicate Transactions)
- **Ab Initio:** Dedup by txn_id, outputs unique records.
- **PySpark:**
  - `dropDuplicates(["txn_id"])` matches deduplication key.
  - **✅ Correct** — Deduplication logic and key.

### 5. JOIN (Enrich with Product Info)
- **Ab Initio:** Inner join on product_sku, enriches with category and standard_cost, outputs unused records.
- **PySpark:**
  - `deduped_df.alias("txn").join(product_dim_df.alias("prod"), col("txn.product_sku") == col("prod.product_sku"), "inner")`
  - `.select()` includes all required columns (txn_id, store_id, txn_date, product_sku, category, total_amount, standard_cost, tax_amount, final_bill, loyalty_points).
  - Product lookup misses handled via `left_anti` join.
  - **✅ Correct** — Join keys, type, enrichment columns, and miss logic.

### 6. REFORMAT (Apply Pricing Rules)
- **Ab Initio:** Calls pricing_rules.xfr, outputs enriched DML.
- **PySpark:**
  - `transform_pricing_logic(enriched_df)` matches XFR logic (tax calculation, final_bill, loyalty_points).
  - **✅ Correct** — XFR function placement and logic.

### 7. SORT (Prepare for Rollup)
- **Ab Initio:** Sort by store_id, txn_date.
- **PySpark:**
  - `orderBy("store_id", "txn_date")` matches sort keys.
  - **✅ Correct** — Sorting logic and keys.

### 8. ROLLUP (Store Aggregation)
- **Ab Initio:** Calls store_rollup.xfr, aggregates by store_id, txn_date, outputs summary DML.
- **PySpark:**
  - `transform_rollup_logic(sorted_df)` matches XFR logic (groupBy, sum, count, report_date).
  - **✅ Correct** — Aggregation logic and schema.

### 9. OUTPUT FILE (Final Summary)
- **Ab Initio:** Writes summary to daily_summary.dat, applies summary DML.
- **PySpark:**
  - `summary_df.coalesce(1).write.mode("overwrite").option("delimiter", "|").option("header", "false").csv(summary_output_path)`
  - **✅ Correct** — Output logic and file path.

### 10. OUTPUT FILE (Cleanse Rejects)
- **Ab Initio:** Writes rejects to ERROR_LOG_PATH, includes error_message.
- **PySpark:**
  - `reject_data_df.withColumn("error_message", lit("Invalid or missing required fields"))` matches reject DML.
  - **✅ Correct** — Output logic and error message.

### 11. OUTPUT FILE (Product Lookup Misses)
- **Ab Initio:** Writes product lookup misses to PRODUCT_MISS_PATH.
- **PySpark:**
  - `product_misses_df.coalesce(1).write.mode("overwrite").option("delimiter", "|").option("header", "false").csv(PRODUCT_MISS_PATH)`
  - **✅ Correct** — Output logic and file path.
